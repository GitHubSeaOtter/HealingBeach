# NAMI — Healing Beach

iPhoneのSafariで、あなただけの南国ビーチを散歩する3Dブラウザアプリです。
Three.js / WebGL 2 と Web Audio API を使用し、画像・音源の外部配信サービスを必要としません。

## できること

- GPUで動く波、浅瀬の光、波打ち際の泡、反射する太陽、夜空と月。
- 白い砂浜、風に揺れるヤシ、沖の島とカヌー、休憩小屋、飛ぶ鳥。
- タイトル画面を挟まず、起動直後から左のタッチパッドで移動、景色のドラッグで見回す。同時に操作できます。
- 朝・昼・夕暮れ・夜の切り替え、時間スライダー、約12分で一日が巡る自動進行。
- 波・風・鳥の生成環境音と、カリンバ／竹笛／ハンドパンの響きをイメージしたオリジナル生成音楽。
- 環境音と音楽の独立音量、音楽なし、消音。設定は端末に保存。
- 自動／高画質／省電力。バックグラウンドでは描画と音を停止。

音楽は実際の楽器の録音ではなく、Web Audioによる合成です。Safariの自動再生制限に合わせて、音は右上の音ボタンへのタップ後に開始します。

## 開発・iPhoneからのアクセス

Node.js 20.19以降（推奨22以降）を使用します。

```sh
npm ci
npm run dev
```

PCとiPhoneを同じWi-Fiに接続し、Viteが表示するNetwork URL（例 `http://192.168.1.10:5173`）をSafariで開きます。
ターミナルのLocal URLはPC自身専用です。ファイアウォールで開発用ポートへの接続を許可する必要がある場合があります。

PCでは WASD / 矢印キーで移動、ドラッグで視点操作。「はじめの景色へ」で位置と視点をリセットします。

## 確認・配布

```sh
npm test
npm run build
npm run preview
```

`dist/` を任意の静的Webホスティングで配信できます。相対パスでビルドするので、GitHub Pages等のサブディレクトリにも配置可能です。
`file://` で直接開かず、HTTP/HTTPSで配信してください。mainへのpush時にGitHub Actionsがテストとビルドを実行し、配信用成果物を保存します。ホスティングの自動公開は行いません。

## 対応と検証範囲

WebGL 2とWeb Audioに対応する現行iPhone Safariを対象とします。横向き・縦向き、セーフエリア、ポインターの同時操作に対応しています。
負荷が高い場合は「省電力」を選択してください。音は端末の音量やSafari側の再生状態にも依存し、タブ復帰後に再タップが必要な場合があります。

ユニットテストでは移動方向、歩行範囲、復帰時の移動量、時間の周回、音楽の周波数を検証します。実機iPhoneでの描画品質、長時間の発熱・電池消費、音質は別途確認が必要です。

初版はChromiumのiPhone 13エミュレーションで、本番ビルドの2本指操作、縦横表示、音の開始・停止・再開、3種類の音楽、時間・画質変更、設定の再読み込みを確認済みです。実機Safariでの検証を代替するものではありません。

## 構成

- `src/scene.js`: Three.jsのシーンと手続き的な植物・建物
- `src/shaders.js`: GPUの海・空シェーダー
- `src/audio.js`: 環境音と楽器音色の生成、再生制御
- `src/main.js`: タッチ、設定、ライフサイクル、描画品質
- `src/world.js`: 地形、歩行範囲、時間変化

この島は想像上の風景です。表示する座標は雰囲気を表すもので、実在する私有地の再現ではありません。
